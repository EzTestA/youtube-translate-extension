## English Version

> Browser extension that adds translation buttons for YouTube comments and live chat using Google Translate API.

---

## 📖 Description

![YouTube Translator](https://img.shields.io/badge/YouTube-Translator-blue) ![Version](https://img.shields.io/badge/version-0.1.0-green) ![License](https://img.shields.io/badge/license-MIT-orange)

**YouTube Translate Extension** is a browser extension that adds the ability to translate comments and live chat on YouTube using the Google Translate API.

> ⚠️ **Note:** This extension uses an unofficial Google Translate API. For this reason, it **cannot be published** in the Chrome Web Store.

## 📥 Installation

### Option 1: Download from Releases

1. Go to the **Releases** section of this repository
2. Download the latest `.zip` archive
3. Extract the archive to a convenient location

### Option 2: Clone the Repository

```bash
git clone https://github.com/EzTestA/youtube-translate-extension
```

### Loading the Extension in Your Browser

1. Open your browser (Chrome, Edge, Brave, or any Chromium-based browser)
2. Go to the extensions page:
   - **Chrome/Edge/Brave:** `chrome://extensions/`
3. Enable **Developer mode** (toggle in the top right corner)
4. Click **Load unpacked**
5. Select the folder with the extension
6. **Alternatively:** Drag and drop the folder directly onto the extensions page

> 💡 The extension will appear in your list of installed extensions.

---

## 🚀 How to Use

1. Click the extension icon in the toolbar
2. Select your preferred translation language from the dropdown menu
3. Open any YouTube video, live stream, or Shorts
4. Click the **🌐 Translate** button under any comment or chat message
5. The translation will appear below the original text

## ✨ Features

- ✅ Translate YouTube comments

## 📥 Установка

### Вариант 1: Скачать из Releases

1. Перейдите в раздел **Releases** этого репозитория
2. Скачайте последний `.zip` архив
3. Распакуйте архив в удобное место

### Вариант 2: Клонировать репозиторий

```bash
git clone https://github.com/EzTestA/youtube-translate-extension
```

### Загрузка расширения в браузере

1. Откройте браузер (Chrome, Edge, Brave или любой другой на основе Chromium)
2. Перейдите на страницу расширений:
   - **Chrome/Edge/Brave:** `chrome://extensions/`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажмите **Загрузить распакованное расширение**
5. Выберите папку с расширением
6. **Или:** Перетащите папку с расширением на страницу с расширениями

> 💡 Расширение появится в списке установленных расширений.

## 🚀 Как пользоваться

1. Нажмите на иконку расширения на панели инструментов
2. Выберите желаемый язык перевода из выпадающего списка
3. Откройте любое видео на YouTube, стрим или Shorts
4. Нажмите на кнопку **🌐 Перевести** под любым комментарием или сообщением в чате
5. Перевод появится под оригинальным текстом
