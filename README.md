# 🌐 YouTube Translator

![YouTube Translator](https://img.shields.io/badge/YouTube-Translator-blue)
![Version](https://img.shields.io/badge/version-0.2.0-green)
![License](https://img.shields.io/badge/license-MIT-orange)

> Расширение для браузера, которое добавляет **кнопку перевода** к комментариям и чату на YouTube. Работает с обычными видео, прямыми эфирами, премьерами и Shorts.

---

## ✨ Возможности

- ✅ **Перевод комментариев** — кнопка «🌐 Перевести» появляется под каждым комментарием
- ✅ **Перевод чата** — работает на стримах и премьерах
- ✅ **Перевод в Shorts** — комментарии в коротких видео тоже переводятся
- ✅ **Мультиязычный интерфейс** — 11 языков интерфейса (English, Русский, Deutsch, Français, Español, Italiano, Português, Українська, 日本語, 한국어, 中文)
- ✅ **Автоопределение языка** — Google Translate сам определяет язык оригинала
- ✅ **Никаких автоматических запросов** — перевод только по нажатию кнопки, безопасно для API
- ✅ **Сохранение настроек** — выбранный язык сохраняется между сессиями
